If you have any datasets you would like to share with the community, please send a thumbnail image, a link to the dataset, and a short description about the dataset to hcomp2010@gmail.com.

Query-based Image Preference Data collected using PictureThis, a game where players are shown a query and are asked to choose from a set of images the one that is the most relevant to the query.
Music Tag Data collected using Tagatune, a game where players are shown either the same song or different songs, and are asked to type in descriptions for their given song.  After reviewing each other’s descriptions, players are asked to guess whether they are given the same song or not.
Image Tag Data collected using ESP Game, a game where players are shown the same image and asked to type descriptions for that images, with the goal of generating descriptions that match with those of their partner.
